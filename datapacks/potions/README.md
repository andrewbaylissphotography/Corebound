# CoreBound Potions

![Minecraft](https://img.shields.io/badge/Minecraft%20Java--26.3-62B47A?logo=minecraft&logoColor=white)
![Datapack](https://img.shields.io/badge/Type-Datapack-blue)

Adds custom potions and increases stack limit from 1 to 64.
Adds recipe book for brewing stand via /dialog potions_menu

potions added: absorption, haste & health boost.
inspired by mcMMO Alchemy - https://wiki.mcmmo.org/en/skills/alchemy


## Development Notes

Some ideas and programming assistance were generated with the help of AI tools (ChatGPT) for brainstorming and function logic. All code was tested, integrated and reviewed manually.

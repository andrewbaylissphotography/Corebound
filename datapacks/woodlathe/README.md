# CoreBound wood lathe

![Minecraft](https://img.shields.io/badge/Minecraft%20Java-1.21.2--26.3-62B47A?logo=minecraft&logoColor=white)
![Datapack](https://img.shields.io/badge/Type-Datapack-blue)

adds recipes that allows the stone cutter to process logs and planks into the items
similar to how stone is used in the stonecutter and crafting table.

The Wood Lathe adds stonecutter recipes for logs and planks, allowing wooden materials to be processed directly into building blocks and utility items.

### Log Recipes

The following recipes are available for each supported wood type.

| Output | Result Count per Log |
|---|---:|
| Planks | 4 |
| Slabs | 8 |
| Stairs | 4 |
| Buttons | 4 |
| Doors | 2 |
| Fence Gates | 1 |
| Pressure Plates | 2 |
| Shelves | 4 |
| Stripped Logs | 1 |

Supported wood types: Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Pale Oak, Poplar, Crimson and Warped.

### Plank Recipes

Planks can be processed directly into slabs and stairs.

| Output | Result Count per Plank |
|---|---:|
| Slabs | 2 |
| Stairs | 1 |

### Utility Recipes

The following recipes accept any supported log.

| Input | Output | Result Count |
|---|---|---:|
| Any supported log | Sticks | 8 |
| Any supported log | Crafting Table | 1 |

### Notes

- All recipes use the vanilla stonecutter interface.
- Result counts indicate the number of items produced per recipe operation.
- Recipes are available when the corresponding input and output items exist in the game.

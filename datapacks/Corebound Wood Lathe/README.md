# CoreBound wood lathe

![Minecraft](https://img.shields.io/badge/Minecraft%20Java-1.21.2--26.3-62B47A?logo=minecraft&logoColor=white)
![Datapack](https://img.shields.io/badge/Type-Datapack-blue)

The Wood Lathe adds stonecutter recipes for logs, stripped logs and planks, allowing wooden materials to be processed directly into building blocks and utility items.

### Log & Stripped Log Recipes

The following recipes are available for each supported log type.

| Output | Result Count per Log or Stripped Log |
|---|---:|
| Planks | 4 |
| Slabs | 8 |
| Stairs | 4 |
| Buttons | 4 |
| Doors | 2 |
| Fence Gates | 1 |
| Pressure Plates | 2 |
| Shelves | 4 |
| Stripped Logs | 1 |

Supported log types: Oak, Spruce, Birch, Jungle, Acacia, Dark Oak, Mangrove, Cherry, Pale Oak, Poplar, Crimson and Warped.

### Plank Recipes

Planks can be processed directly into slabs and stairs.

| Output | Result Count per Plank |
|---|---:|
| Slabs | 2 |
| Stairs | 1 |

### Utility Recipes

The following recipes accept any supported log.

| Input | Output | Result Count |
|---|---|---:|
| Any supported log or stripped log | Sticks | 8 |
| Any supported log or stripped log | Crafting Table | 1 |

### Notes

- All recipes use the vanilla stonecutter.
- Result counts indicate the number of items produced per recipe operation.
- Recipes outputs only show 1 count in the choice preview but when selected it shows correct values.

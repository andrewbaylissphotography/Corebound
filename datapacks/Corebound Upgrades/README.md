# CoreBound Item Upgrades

![Minecraft](https://img.shields.io/badge/Minecraft%20Java-1.21.2--26.3-62B47A?logo=minecraft&logoColor=white)
![Datapack](https://img.shields.io/badge/Type-Datapack-blue)

Allows items to be upgrades through material tiers. gold -> iron -> diamond.
Uses the smithing table and keeps and existing enchantments on the tool.

## Development Notes
Some ideas and programming assistance were generated with the help of AI tools (ChatGPT) for brainstorming and function logic. All code was tested, integrated and reviewed manually.
